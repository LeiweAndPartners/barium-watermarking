The z-test

Back to the README · The paper (arXiv:2301.10226 §2)

Detection is a one-proportion z-test. Under the null hypothesis — text generated without knowledge of the key — each scored token is green with probability γ = 0.5, the fair-coin expectation. The test asks: how many standard deviations is the observed green count above that expectation?

z = (G − γ·T) / √(T·γ·(1−γ))

The z-score is a false-positive rate, not a certainty. A threshold of z = 4 means unwatermarked text exceeds it with probability about 3×10⁻⁵ — the rate at which human text gets flagged, not a measure of how certain a flag is. The prosecutor's fallacy applies: P(flag | human) is not P(human | flag).

Worked example with real numbers: G = 18 green of T = 20 scored at γ = 0.5.

z = (18 − 10) / √(20 × 0.5 × 0.5) = 8 / √5 = 3.578

At z = 3.578 the false-positive rate is about 1.7×10⁻⁴: unwatermarked text reaches this z roughly once in 5,800. That is the honest reading — not "82% certain the text is watermarked".

The false-positive rate is the standard-normal upper tail at z. The verdict compares z against the threshold (default 4.0); below 25 scored positions the package reports an inconclusive verdict, because short or low-entropy text carries no signal.
