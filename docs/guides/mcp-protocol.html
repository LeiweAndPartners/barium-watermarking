The MCP protocol

Back to the README · The MCP specification · The paper (arXiv:2301.10226 §2)

Barium's MCP server speaks JSON-RPC 2.0 over stdio, implemented by hand on the Python standard library — no MCP SDK dependency. Requests are newline-delimited JSON objects in; responses are newline-delimited JSON objects out.

A handshake and a tool call, with real messages:

client → server
{"jsonrpc": "2.0", "id": 1, "method": "initialize", "params": {"protocolVersion": "2024-11-05", "capabilities": {}, "clientInfo": {"name": "demo", "version": "0"}}}
server → client
{"jsonrpc": "2.0", "id": 1, "result": {"protocolVersion": "2024-11-05", "capabilities": {"tools": {}}, "serverInfo": {"name": "barium", "version": "0.1.0"}}}
client → server (notification, no reply)
{"jsonrpc": "2.0", "method": "notifications/initialized", "params": {}}
client → server
{"jsonrpc": "2.0", "id": 2, "method": "tools/list", "params": {}}
server → client
{"jsonrpc": "2.0", "id": 2, "result": {"tools": [detect_watermark, generate_key, selftest]}}
client → server
{"jsonrpc": "2.0", "id": 3, "method": "tools/call", "params": {"name": "detect_watermark", "arguments": {"text": "some text", "key": 123456789}}}
server → client
{"jsonrpc": "2.0", "id": 3, "result": {"content": [{"type": "text", "text": "{\"num_tokens_scored\": 6, ...}"}]}}

The three rules the implementation follows:

1. Every request carries an id; every response echoes it. A notification carries no id and gets no reply — per JSON-RPC 2.0 §4, the server must not answer a notification regardless of method.

2. Unknown methods get error code −32601; unknown tools get −32602; unparseable lines get −32700.

3. Tool errors come back as results with isError: true, not protocol errors — a bad argument is the caller's problem to read, not a broken session.

The three tools: detect_watermark(text, key, z_threshold?) scores text with the z-test (the z-score is a false-positive rate, not a certainty); generate_key() returns a fresh per-deployment key; selftest() runs the embed-then-detect round-trip with the reference demo embedder (a labelled demo, not production generation).

Point any MCP client at it: the command is barium-mcp, transport stdio. The server reads until stdin closes.
